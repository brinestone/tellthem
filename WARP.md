# WARP.md

This file provides guidance to WARP (warp.dev) when working with code in this repository.

## High-level Architecture

This is an Angular web application that helps users promote campaigns and earn rewards. The app uses a component-based architecture with NGXS for state management and PrimeNG for UI components. The `src/app` directory contains the main application logic, with subdirectories for features, shared components, and services.

## Commonly Used Commands

- **Install dependencies:** `pnpm install`
- **Run the development server:** `pnpm start`
- **Run tests:** `pnpm test`
- **Build the application for production:** `pnpm build`
- **Generate a new component:** `pnpm ng generate component component-name`
